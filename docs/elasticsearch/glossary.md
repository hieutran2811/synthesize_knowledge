# Glossary Elasticsearch

| Thuật ngữ | Nghĩa tiếng Việt | Giải thích ngắn |
|---|---|---|
| Analyzer | Bộ phân tích văn bản | Chuỗi character filter, tokenizer và token filter. |
| Cluster state | Trạng thái cụm | Metadata điều phối index, mapping, shard và node. |
| Inverted index | Chỉ mục đảo | Ánh xạ term tới các document chứa term đó. |
| Mapping | Ánh xạ trường | Khai báo kiểu và cách index các field. |
| Replica shard | Shard bản sao | Bản sao tăng khả năng đọc và chịu lỗi. |
| Shard | Phân mảnh | Một Lucene index độc lập trong Elasticsearch. |
