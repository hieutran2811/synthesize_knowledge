# Glossary Angular

| Thuật ngữ | Nghĩa tiếng Việt | Giải thích ngắn |
|---|---|---|
| Change detection | Phát hiện thay đổi | Cơ chế đồng bộ trạng thái component với giao diện. |
| Dependency injection | Tiêm phụ thuộc | Cung cấp dependency qua injector thay vì tự khởi tạo. |
| Directive | Chỉ thị | Thành phần bổ sung hành vi hoặc cấu trúc cho template. |
| Hydration | Phục hồi phía client | Gắn Angular vào HTML đã render từ server. |
| Signal | Tín hiệu phản ứng | Primitive quản lý trạng thái và dependency phản ứng. |
| Standalone component | Component độc lập | Component không cần khai báo trong NgModule. |
