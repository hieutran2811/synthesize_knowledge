# Glossary Prometheus & Grafana

| Thuật ngữ | Nghĩa tiếng Việt | Giải thích ngắn |
|---|---|---|
| Cardinality | Số lượng chuỗi thời gian | Số tổ hợp label duy nhất tạo ra series. |
| Dashboard | Bảng quan sát | Tập panel trình bày metric, log hoặc trace. |
| Label | Nhãn | Cặp key-value định danh chiều của time series. |
| PromQL | Ngôn ngữ truy vấn Prometheus | Ngôn ngữ chọn và biến đổi time series. |
| Recording rule | Quy tắc ghi trước | Truy vấn được tính định kỳ và lưu thành series mới. |
| SLO | Mục tiêu mức dịch vụ | Mức reliability mục tiêu đo bằng SLI trong một cửa sổ. |
