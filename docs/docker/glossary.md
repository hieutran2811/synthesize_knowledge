# Glossary Docker

| Thuật ngữ | Nghĩa tiếng Việt | Giải thích ngắn |
|---|---|---|
| Build context | Ngữ cảnh build | Tập file được gửi cho builder khi tạo image. |
| Container | Tiến trình được cô lập | Tiến trình dùng namespace, cgroup và filesystem riêng. |
| Image | Ảnh đóng gói bất biến | Tập layer và metadata dùng để tạo container. |
| Layer | Lớp filesystem | Phần thay đổi bất biến có thể cache và tái sử dụng. |
| Namespace | Không gian tên | Cơ chế kernel cô lập process, network, mount và tài nguyên khác. |
| Registry | Kho image | Dịch vụ lưu trữ và phân phối container image. |
