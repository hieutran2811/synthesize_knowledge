# Glossary WebSocket

| Thuật ngữ | Nghĩa tiếng Việt | Giải thích ngắn |
|---|---|---|
| Backpressure | Áp lực ngược | Cơ chế kiểm soát producer khi consumer xử lý không kịp. |
| Close frame | Frame đóng kết nối | Frame điều khiển kết thúc phiên với mã và lý do. |
| Frame | Khung dữ liệu | Đơn vị truyền tải của giao thức WebSocket. |
| Handshake | Bắt tay | Quá trình nâng cấp HTTP connection sang WebSocket. |
| Heartbeat | Nhịp kiểm tra sống | Ping/pong hoặc message ứng dụng để phát hiện kết nối chết. |
| Subprotocol | Giao thức con | Protocol ứng dụng được thương lượng trên WebSocket. |
