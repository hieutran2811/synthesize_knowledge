# Glossary Linux

| Thuật ngữ | Nghĩa tiếng Việt | Giải thích ngắn |
|---|---|---|
| Cgroup | Nhóm điều khiển | Cơ chế giới hạn và đo tài nguyên của nhóm process. |
| File descriptor | Mô tả file | Số nguyên đại diện file, socket, pipe hoặc tài nguyên I/O. |
| Namespace | Không gian tên | Cơ chế cô lập góc nhìn tài nguyên của process. |
| Process | Tiến trình | Instance đang chạy của một chương trình. |
| Signal | Tín hiệu | Thông báo bất đồng bộ gửi tới process/thread. |
| System call | Lời gọi hệ thống | Giao diện để chương trình yêu cầu dịch vụ từ kernel. |
