# Glossary Kubernetes

| Thuật ngữ | Nghĩa tiếng Việt | Giải thích ngắn |
|---|---|---|
| Controller | Bộ điều khiển | Vòng lặp đưa trạng thái thực về trạng thái mong muốn. |
| Deployment | Khai báo triển khai | Quản lý ReplicaSet và rollout Pod stateless. |
| Ingress | Luồng vào HTTP | API định tuyến HTTP/HTTPS từ ngoài cluster. |
| Pod | Đơn vị chạy nhỏ nhất | Nhóm container chia sẻ network và volume. |
| Reconciliation | Đối soát trạng thái | Quá trình liên tục sửa chênh lệch desired/actual state. |
| Service | Điểm truy cập ổn định | Địa chỉ và cơ chế chọn tập Pod backend. |
