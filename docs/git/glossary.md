# Glossary Git

| Thuật ngữ | Nghĩa tiếng Việt | Giải thích ngắn |
|---|---|---|
| Commit | Bản ghi thay đổi | Snapshot có metadata và liên kết tới commit cha. |
| HEAD | Con trỏ hiện tại | Tham chiếu tới branch hoặc commit đang checkout. |
| Index | Vùng chuẩn bị | Trạng thái trung gian dùng để tạo commit tiếp theo. |
| Rebase | Đặt lại nền commit | Phát lại commit trên một base mới. |
| Reflog | Nhật ký tham chiếu | Lịch sử cục bộ của việc di chuyển ref/HEAD. |
| Remote | Kho từ xa | Tên ánh xạ tới repository và các remote-tracking ref. |
